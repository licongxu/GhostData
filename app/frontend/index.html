GhostData

Find when a data agent is wrong.

Upload a table. An agent proposes silent failures. Daytona measures each one in its own sandbox. A Ghost is the case where your checks still pass and the frozen model drops.

Architecture

1 · You Table in

Upload a labeled CSV. Name the prediction target.

→
2 · Agent ×1 Analysis agent

Inspects the table and writes failure hypotheses.

→
3 · Daytona ×N Measure

Each sandbox simulates that world, writes the dataset, runs checks, scores the frozen model.

→
4 · Ghost Evidence out

Checks pass. Model drops. Download the four artifacts.
