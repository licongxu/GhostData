GhostData

Verify data-analysis agents.

They propose hypotheses. Daytona measures each one in isolation. We keep only a Ghost — a measured counterexample. The agent cannot declare victory.

How it works

The agent proposes. Daytona verifies.

Architecture

1 · You CSV + task

Upload a labeled table. Say what the agent was predicting.

→
2 · Daytona ×1 Analysis agent

Inspects the table and writes hypotheses. It cannot declare a Ghost.

→
3 · Daytona ×N Verifiers

Each hypothesis: transform, your checks, frozen-model score.

→
4 · Ghost Keep the failure

Checks still pass. Model metric drops. Artifacts download.
